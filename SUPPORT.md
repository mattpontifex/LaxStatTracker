# LaxStatTracker Support

Thank you for using LaxStatTracker.

If you have questions, encounter a problem, or would like to request a feature, please contact support.

## Contact Support

For support requests, bug reports, or feature suggestions:

- Open an issue in this GitHub repository
- Contact the developer through the App Store support link

## Frequently Asked Questions

### Does LaxStatTracker require an internet connection?

No. Core game tracking and analytics features operate entirely offline.

### Do I need to create an account?

No. LaxStatTracker does not require account creation or login.

### Where is my data stored?

All data is stored locally on your device unless you explicitly export or share it.

### Can I transfer data between devices?

Data can be transferred using the app's export and import features when available.

### I found a bug. What should I do?

Please submit a detailed bug report including:
- Device model
- iOS version
- App version
- Steps to reproduce the issue
